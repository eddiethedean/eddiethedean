## Selected work

| Project | What it does | Built with |
| --- | --- | --- |
| [**Strixonomy**](https://github.com/eddiethedean/strixonomy) | A VS Code environment for browsing, editing, querying, reasoning over, and validating OWL/RDF/OBO ontologies. | Rust · TypeScript · LSP |
| [**ModelVault**](https://github.com/eddiethedean/modelvault) | A schema-first embedded database that stores Pydantic models and dataclasses directly, with validation, indexes, and migrations. | Rust · Python · PyO3 |
| [**Sparkless**](https://github.com/eddiethedean/robin-sparkless) | A PySpark-compatible DataFrame engine for fast local pipelines and JVM-free unit tests. | Rust · Python · Polars |
| [**PydanTable**](https://github.com/eddiethedean/pydantable) | Strongly typed DataFrames combining Pydantic schemas with a Rust execution engine. | Python · Rust · Pydantic |
| [**Moltres**](https://github.com/eddiethedean/moltres) | A DataFrame layer for SQL with pushdown execution, CRUD operations, and async support. | Python · SQLAlchemy · SQL |
| [**PolarPandas**](https://github.com/eddiethedean/polarpandas) | A pandas-compatible API backed by Polars for familiar syntax with faster execution. | Python · Polars |

## What I care about

- **Typed interfaces** that move correctness into the API instead of leaving it to runtime surprises
- **Fast local workflows** that make serious data tooling pleasant to test and iterate on
- **Interoperability** across Python, Rust, SQL, Spark, Polars, Pydantic, and semantic-web standards
- **Complete products**, including documentation, release automation, examples, migration paths, and honest limitations

## Start here

- Building data pipelines or testing PySpark code? Explore [Sparkless](https://github.com/eddiethedean/robin-sparkless).
- Working with application models and local persistence? Try [ModelVault](https://github.com/eddiethedean/modelvault).
- Managing ontologies in a modern editor? Install [Strixonomy](https://github.com/eddiethedean/strixonomy).
- Looking for typed DataFrames? See [PydanTable](https://github.com/eddiethedean/pydantable).
